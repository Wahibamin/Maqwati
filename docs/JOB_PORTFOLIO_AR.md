# نصوص جاهزة للتقديم على وظيفة — مقوتي

**المطور:** وهيب الكبودي | Wahib Al-Kaboudi

## وصف مختصر لمستودع GitHub

تطبيق Flutter محاسبي عربي يعمل محليًا لإدارة مبيعات ومشتريات وديون ومخزون البائعين الصغار، مع SQLite وتقارير مالية ونسخ احتياطي.

## صياغة للسيرة الذاتية

**مقوتي (Maqwati) — تطبيق إدارة محاسبية وميدانية | Flutter / Dart / Riverpod / Drift / SQLite**

طورت تطبيق Android عربيًا لتنظيم عمليات البيع النقدي والآجل، وحسابات الزبائن والموردين، والمصاريف والمرتجعات والتالف. صممت تخزينًا محليًا ومعاملات محاسبية لحساب تكلفة البضاعة المباعة (COGS) وحركة الصندوق، مع ترحيل تدريجي لقاعدة البيانات واختبارات للقواعد المحاسبية.

## تقديم قصير في المقابلة

«من مشاريعي تطبيق مقوتي، وهو نظام محاسبي خفيف ومخصص لاحتياجات البائعين الصغار. اهتممت فيه بتصميم واجهات عربية سريعة للعمل اليومي، لكن الجزء الأكثر أهمية كان فصل الإيرادات والديون والتكلفة وحركة النقد، وإدارة البيانات باستخدام SQLite وRiverpod. أضفت اختبارات للسلوك المحاسبي وترحيل قاعدة البيانات، واحتفظت بتوثيق واضح لما تم التحقق منه وما يحتاج اختبارًا ميدانيًا إضافيًا».

## ملاحظة النزاهة المهنية

سُجّل نجاح 20 اختبارًا محاسبيًا وقاعدة بيانات في تقارير التطوير السابقة بتاريخ 28 أكتوبر 2026، ولم يُعَد تنفيذها عند إنشاء هذه الحزمة. لا تدّعِ أن رفع المشروع وحده يعني اعتماد التطبيق للإنتاج التجاري.
